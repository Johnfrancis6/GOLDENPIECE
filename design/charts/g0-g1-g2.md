## 1. G0 — Base (every chart)

| Part | Rule |
|---|---|
| Plot | full screen width; 20 dp left margin; right gutter 56 dp for value labels; height 210 dp on Home (P6 may go to 240) |
| Grid | **none** |
| Value labels | 3, on the right, 11/14 `text.secondary`, tabular digits, abbreviated (F6: "13,3 M") |
| Time labels | 4 at most, under the plot, 11/14 `text.secondary` ("janv.", "9 nov.") |
| Scrub (touch and drag) | vertical 1 dp line `text.secondary` 60 %, point 12 dp in the series colour with a 2.5 dp ring in the page colour; the **hero amount above shows the value** of the touched point and the line under it shows the date ("mardi 12 août 2026"); no tooltip bubble; release → everything returns. Long-press not needed: touching the plot starts the scrub (vertical scroll still wins if the gesture is vertical) |
| Previous / next | two 40 dp icon buttons (`chevron-left`, `chevron-right`, 48 dp targets) under the plot step through points (same effect as the scrub); TalkBack reads "12 août 2026, 12 886 400 francs CFA" |
| Table view | "Voir en tableau" text button (C1) → tall C9 sheet listing date / value |
| Freshness | 12/16 `text.secondary` line under the controls ("Mis à jour le 22 nov., 14:05"), C14 tag when delayed |
| Summary | each chart has a TalkBack sentence ("Patrimoine en hausse de 20 % depuis le 1er janvier, de 11,2 à 13,4 millions") |
| < 2 points | dashed 1 dp hairline box (120 dp), "Données insuffisantes" 15 Medium + reason 13 `text.secondary`; no axes |
| Series palette | `colour.chart` (F1) for multi-series charts (G3-G7); single series use the line colour below |

## 2. G1 — Line / area

- Line 2.5 dp, round caps/joins, smoothed (monotone cubic, never
  overshooting the data), colour `#FF7A2F` dark / `#D9560F` light
  (3.6:1 on `#F4F4F4`).
- Area under the line: vertical gradient of the line colour, alpha
  0.24 dark / 0.16 light at the top to 0 at the plot bottom, 13 eased
  stops (alpha × (1 − t)^1.8) against banding [check on the Tecno].
- Drawdown (P8): same rules, area **below zero** in `loss` tint, line in
  `loss`; zero line 1 dp `text.secondary` 40 %.
- Monthly series as line: same, points 6 dp at each month.

## 3. G2 — Sparkline

56 × 24 dp, line 1.75 dp, no area, no labels, no scrub; colour `gain`
if the last value ≥ the first, else `loss`; the percentage next to it
carries the same colour and the C5 sign. Used in B9 quote rows (Home,
P7).

## 4. Motion (M8)

| Event | Motion |
|---|---|
| First view | line drawn left → right (Skia path trim) `chartLine` 1100 ms, `enter`; area fades in over 700 ms after 400 ms |
| Period change (C12 bar) | line morphs old → new `chartPeriodMorph` 550 ms, `morph` easing (resampled to the same point count); value and time labels then swap with a `quick` fade; hero amount count-up (C5) |
| Scrub | follows the finger every frame (UI thread), no easing |
| Reduced motion | drawn at once; period change cross-fades 150 ms |

Target ≥ 45 fps on the reference phone (to measure in the first build).

## 5. Where used

G1: Home (B8, year by default), P6, P8 (drawdown), monthly series.
G2: B9 quote rows. G0 rules apply to G3-G8.
